## Selected work

### [Yor Zenith](https://github.com/yorayriniwnl/Yor-Zenith)

Solar planning for rooftops and parcels. Ranks irradiance with PostGIS, models roof geometry in 3D, simulates panel placement across an annual cycle, and brings ROI, payback, and subsidy analysis into one workflow.

`TypeScript` `Next.js` `PostGIS` `Three.js` `Python`

### [Yor Helios](https://github.com/yorayriniwnl/Yor-Helios)

Realtime alerting for metrics that cannot wait for a dashboard refresh. Streams threshold and anomaly alerts through FastAPI and WebSockets into channel-specific dashboards, with a Docker Compose stack for local deployment.

`Python` `FastAPI` `WebSocket` `Docker`

### [Yor AI vs Real](https://github.com/yorayriniwnl/Yor-Ai-vs-real-image)

Synthetic-versus-real image classification using LBP and GLCM texture features with a Platt-calibrated SVM. The current model reports 78% held-out accuracy with sub-two-second local inference.

`Python` `OpenCV` `Scikit-learn` `Streamlit`

### [Personal portfolio](https://github.com/yorayriniwnl/Yor-Ayrin-iwnl)

The portfolio itself is a small systems exercise: a 4,000-point GPU particle field, lazy-loaded case studies, GitHub-synced work data, and a tested React Three Fiber frontend.

`TypeScript` `React` `Three.js` `Vite` `Vitest`

### Yor Talks

Realtime communication platform with Socket.IO over Express, React and Vite on the frontend, Postgres through Drizzle, Redis for queueing, JWT access and refresh tokens, and Zod validation. A public repository link will be added when the current version is ready to represent the project accurately.

`TypeScript` `Express` `Socket.IO` `React` `PostgreSQL` `Redis`
